# Portale — Entrega Hito 1

## 1. DER
Archivo: `docs/DER.png` y fuente `docs/DER.dot`.

## 2. Modelo Relacional
Archivo: `docs/modelo_relacional.md` y script `database/portale_hito1.sql`.

Tablas del Hito 1:
- Roles
- Usuarios
- Artistas
- Generos
- Sesiones
- Password_resets (soporte técnico)

## 3. CodeIgniter 4 / MVC
Se incluye estructura de `app/Controllers`, `app/Models`, `app/Views`, `app/Filters`, `app/Config` y migraciones.

## 4. Login y Register
Incluidos con `password_hash()`, `password_verify()`, sesiones y protección CSRF.

## 5. Primer módulo funcional
CRUD de Géneros. El listado requiere sesión iniciada y las operaciones de alta, edición y baja requieren rol Administrador.
